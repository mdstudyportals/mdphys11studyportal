Medical Physiology — app version

Upload ALL of these files, unchanged, to one folder on a website that uses https (for example GitHub Pages).
  index.html            the portal (still locked: only students on your class list can open it)
  manifest.webmanifest  the app's name, colors and icons
  sw.js                 keeps the portal on the device so it opens offline, and installs updates
  icon-*.png, apple-touch-icon.png   the app icons

Students open the link, then install it: Android or computer (Chrome, Edge): the Install button; iPhone or iPad (Safari): Share > Add to Home Screen.
To update: build again in the Portal Builder, download the app version, and upload the new files over the old ones.
